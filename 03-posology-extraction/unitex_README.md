# README - unitex.py

## Purpose

`unitex.py` is a Python script that orchestrates the UNITEX natural language processing platform to extract medical posologies (medication prescriptions) from a medical corpus. The script automates a multi-step workflow including text normalization, tokenization, dictionary compression, and grammar-based pattern matching to identify and extract medication dosage information.

---

## Requirements

### Dependencies
- Python 3.x
- `os` module (built-in)
- `os.path` module (built-in)

### UNITEX Installation
- **UNITEX-GramLab** must be installed and operational
- Script should be located in: `C:\...\Unitex-GramLab\App>` (as per project specifications)
- `UnitexToolLogger` command-line tool must be accessible from script location
- UNITEX installation path should be in system PATH or accessible from script directory

### Input Files

#### 1. **corpus-medical.txt** (Medical Corpus)
- **Encoding**: UTF-8 without BOM
- **Format**: Plain text file with medical prescriptions and medication information
- **Content**: Medical records containing medication names, dosages, and administration frequencies
- **Location**: Same directory as script

#### 2. **Norm.txt** (Normalization Rules)
- **Format**: UNITEX normalization rules file
- **Content**: Defines text normalization rules (accents, special characters, etc.)
- **Purpose**: Preprocesses text before tokenization
- **Location**: UNITEX system resources directory

#### 3. **Alphabet.txt** (Language Alphabet Definition)
- **Format**: UNITEX alphabet description file
- **Encoding**: UTF-8
- **Critical Role**: 
  - Describes all characters in the target language (French in this case)
  - Defines lowercase-to-uppercase letter mappings
  - Required by UNITEX for proper tokenization and pattern matching
  - Used in **Phase 2: Tokenization** (explicit call with `-a Alphabet.txt` parameter)
  - Also used in **Phase 6: Pattern Matching** with the Locate command
  
**Detailed Explanation of Alphabet.txt:**

The Alphabet.txt file is essential for UNITEX functioning and serves multiple critical purposes:

1. **Character Definition**: Lists all valid characters in French language
   - Standard ASCII letters: a-z, A-Z
   - Accented characters: à, â, ä, é, è, ê, ë, ç, ù, û, etc.
   - Special characters and symbols used in medical texts
   
2. **Case Mapping**: Establishes mappings between lowercase and uppercase versions
   - Example entries in Alphabet.txt:
     ```
     a A
     b B
     c C
     ...
     é É
     è È
     ê Ê
     ```
   
3. **Tokenization Reference**: Tells UNITEX how to break text into tokens
   - Helps identify word boundaries
   - Distinguishes between letters and non-letter characters
   - Handles multi-character sequences (like "œ" in French)
   
4. **Pattern Matching**: Used by Locate command to properly match characters in grammar rules
   - Ensures medication names are recognized regardless of case
   - Handles accented characters in French pharmaceutical names
   
**Example Alphabet.txt Structure:**
```
a A
b B
c C
d D
e E
f F
...
é É
è È
ê Ê
ë Ë
ç Ç
à À
â Â
ô Ô
û Û
ù Ù
...
0 0
1 1
...
9 9
/ /
. .
, ,
```

**Usage in Script**: 
- Line 6: `Tokenize corpus-medical.snt -a Alphabet.txt` - Used to tokenize the corpus
- Line 8: `Dico -t corpus-medical.snt -a Alphabet.txt ...` - Used for dictionary application
- Line 10: `Locate -t corpus-medical.snt posologie.fst2 -a Alphabet.txt ...` - Used for pattern matching

Without Alphabet.txt, UNITEX cannot:
- Properly recognize word boundaries
- Handle French accented characters in medications
- Apply case-insensitive pattern matching
- Generate correct concordance results

#### 4. **subst.dic** (Medication Dictionary)
- **Encoding**: UTF-16 LE with BOM
- **Format**: DELAF dictionary format
- **Content**: List of medication names by active substance
- **Generated by**: `extraire.py` (Step 1)
- **Used for**: Medication name recognition in patterns
- **Example entries**:
  ```
  abacavir,.N+subst
  abatacept,.N+subst
  metformine,.N+subst
  simvastatine,.N+subst
  ```

#### 5. **Dela_fr.bin** (French Dictionary Binary)
- **Encoding**: Binary UNITEX dictionary format
- **Format**: Compiled French lexical dictionary
- **Source**: UNITEX system resources
- **Content**: Comprehensive French language dictionary
- **Purpose**: Provides morphological and syntactic information for French words
- **Critical**: Dela_fr.inf file must be present alongside Dela_fr.bin
- **Use**: Applied in the Dico command for dictionary-based tokenization

#### 6. **posologie.grf** (Extraction Grammar)
- **Format**: UNITEX graph format (.grf)
- **Content**: Grammar rules for posology pattern extraction
- **Purpose**: Defines patterns to match and extract medication dosages
- **Patterns Include**:
  - Medication names (from subst.dic)
  - Dosage amounts (50 mg, 20 ml, etc.)
  - Administration frequencies (2 times per day, 3 times daily, etc.)
  - Time indicators (morning, evening, 8 hours, etc.)
  - Treatment duration (for one month, for 21 days, etc.)

## How It Works

### Phase 1: Environment Setup
```python
if path.exists("corpus-medical_snt"):
    os.system("rd /s corpus-medical_snt")
os.mkdir("corpus-medical_snt")
```
**Purpose**: Clean environment for fresh processing
- Removes previous output directory if exists
- Creates new empty directory for this run
- Ensures clean separation between runs
- **Note**: Uses Windows command `rd` (remove directory)

### Phase 2: Text Normalization
```python
os.system("UnitexToolLogger Normalize corpus-medical.txt -r Norm.txt")
```
**Command**: `UnitexToolLogger Normalize`
**Input**: `corpus-medical.txt`, `Norm.txt`
**Purpose**: Preprocess text before tokenization
**Actions**:
- Applies normalization rules from Norm.txt
- Handles accents and special characters
- Converts text to canonical form
- Example: "café" might be normalized to "cafe" depending on rules
- Output: Modified text in corpus-medical.snt

### Phase 3: Tokenization
```python
os.system("UnitexToolLogger Tokenize corpus-medical.snt -a Alphabet.txt")
```
**Command**: `UnitexToolLogger Tokenize`
**Input**: `corpus-medical.snt`, `Alphabet.txt`
**Purpose**: Break text into individual tokens (words, punctuation, etc.)
**Actions**:
- Uses Alphabet.txt to identify valid characters
- Determines word boundaries based on character definitions
- Creates internal data structures for efficient processing
- Handles French accented characters properly
- **Critical**: Alphabet.txt must be present for correct tokenization
- Output: Tokenized representation in corpus-medical_snt directory

### Phase 4: Dictionary Compression
```python
os.system("UnitexToolLogger Compress subst.dic")
```
**Command**: `UnitexToolLogger Compress`
**Input**: `subst.dic` (medication dictionary)
**Purpose**: Convert text dictionary to binary format
**Output**: `subst.bin` (compressed/binary format)
**Benefits**:
- Faster lookup during pattern matching
- Reduced memory usage
- Optimized for UNITEX operations

### Phase 5: Dictionary Application
```python
os.system("UnitexToolLogger Dico -t corpus-medical.snt -a Alphabet.txt subst.bin Dela_fr.bin")
```
**Command**: `UnitexToolLogger Dico`
**Inputs**: 
- `corpus-medical.snt` (tokenized corpus)
- `Alphabet.txt` (character mappings)
- `subst.bin` (medication dictionary - compressed)
- `Dela_fr.bin` (French language dictionary)
**Purpose**: Apply dictionaries to recognize words
**Actions**:
- Matches words in corpus against both dictionaries
- Tags medication names with grammatical/semantic information
- Tags French words with morphological information
- Creates internal representation with dictionary references
- Output: Enhanced representation in corpus-medical_snt directory

### Phase 6: Grammar Compilation
```python
os.system("UnitexToolLogger Grf2Fst2 posologie.grf")
```
**Command**: `UnitexToolLogger Grf2Fst2`
**Input**: `posologie.grf` (grammar file)
**Purpose**: Compile posology extraction grammar to transducer format
**Output**: `posologie.fst2` (compiled grammar)
**Why Needed**:
- Converts human-readable grammar rules to machine-readable format
- Optimizes for efficient pattern matching
- **Grammar patterns include**:
  - Medication names: `<N+subst>` (tagged by subst.dic)
  - Dosages: numeric patterns like "50 mg", "2 ml", "500 UI"
  - Frequencies: "2 fois par jour", "1 fois/jour", "3 times daily"
  - Times: "le matin", "le soir", "à 8h", "morning"
  - Durations: "pendant un mois", "pendant 21 jours", "de J1 à J7"

### Phase 7: Pattern Matching / Extraction
```python
os.system("UnitexToolLogger Locate -t corpus-medical.snt posologie.fst2 -a Alphabet.txt -L -I --all")
```
**Command**: `UnitexToolLogger Locate`
**Inputs**:
- `corpus-medical.snt` (tokenized corpus)
- `posologie.fst2` (compiled extraction grammar)
- `Alphabet.txt` (character mappings)
**Flags**:
- `-t` : Process text file (corpus)
- `-a Alphabet.txt` : Use alphabet for character recognition
- `-L` : Case-insensitive matching
- `-I` : Include pattern output
- `--all` : Extract all matches (not just first match)
**Purpose**: Find all occurrences of posology patterns in corpus
**Actions**:
- Searches corpus for pattern matches
- Extracts matching text segments
- Records positions and context
- Output: Creates concordance index file

**Example Matches Found**:
```
METFORMINE 850 mg 3 fois par jour
SIMVASTATINE 20 mg : 1 cp/j à 8 heures pendant un mois
LOVENOX 0,4 ml : 1 injection/jour le soir
PLAVIX 75 mg : 1 cp/jour
```

### Phase 8: Concordance Generation
```python
os.system("UnitexToolLogger Concord corpus-medical_snt/concord.ind -f \"Courrier new\" -s 12 -l 40 -r 55")
```
**Command**: `UnitexToolLogger Concord`
**Input**: `corpus-medical_snt/concord.ind` (extraction index)
**Flags**:
- `-f "Courrier new"` : Font name for HTML output
- `-s 12` : Font size (12 points)
- `-l 40` : Left context width (40 characters before match)
- `-r 55` : Right context width (55 characters after match)
**Purpose**: Format extraction results as readable HTML
**Output**: `corpus-medical_snt/concord.html`
**Result Format**:
- HTML table or list format
- Shows each extracted posology
- Includes surrounding context
- Numbered for easy reference
- Human-readable and suitable for review
- Ready for import into database

## Technical Notes

### Command-Line Tool Usage
- Uses `UnitexToolLogger` wrapper for UNITEX commands
- Provides logging and error handling
- More robust than direct Unitex.exe calls

### UNITEX Commands Explained

| Command | Purpose | Key Inputs | Key Outputs |
|---------|---------|-----------|-------------|
| Normalize | Text preprocessing | corpus, rules | Normalized text |
| Tokenize | Break into tokens | text, alphabet | Token streams |
| Compress | Dictionary optimization | .dic file | .bin file |
| Dico | Apply dictionaries | corpus, dicts | Tagged corpus |
| Grf2Fst2 | Compile grammar | .grf file | .fst2 file |
| Locate | Find patterns | corpus, grammar | Matches |
| Concord | Format results | Index file | HTML output |

### File Encoding Management
- **Input**: UTF-8 without BOM (corpus-medical.txt)
- **Processing**: UNITEX handles multiple encodings
- **Output**: HTML (UTF-8) in concord.html
- **Dictionaries**: UTF-16 LE with BOM (subst.dic)

### Performance Considerations
- `--all` flag ensures all matches are found
- Case-insensitive matching (`-L`) is important for medication names
- Alphabet.txt must be complete for all characters
- Dela_fr.bin should be indexed (Dela_fr.inf present)

## Common Issues & Solutions

### Issue: "UnitexToolLogger: command not found"
**Cause**: UNITEX not in system PATH or wrong directory
**Solution**: 
- Verify UNITEX installation
- Add UNITEX/App to system PATH
- Or copy script to UNITEX/App directory

### Issue: "corpus-medical_snt: directory cannot be deleted"
**Cause**: Files still in use or permission issues
**Solution**:
- Close any file explorers viewing the directory
- Run script with administrator privileges
- Check file permissions

### Issue: "Alphabet.txt not found"
**Cause**: File missing or in wrong location
**Solution**:
- Verify Alphabet.txt exists in same directory
- Check file encoding is UTF-8
- Ensure file is properly formatted with letter pairs

### Issue: No extractions found (empty concord.html)
**Possible Causes**:
- posologie.grf grammar too restrictive
- Medication names not in subst.dic
- Corpus format doesn't match expected patterns
- Dosage format not recognized by grammar

**Solutions**:
- Verify posologie.grf patterns
- Check subst.dic contains expected medications
- Review corpus-medical.txt format
- Test grammar with sample text manually

### Issue: "Dela_fr.inf" error or missing
**Cause**: Binary dictionary index missing
**Solution**:
- Verify Dela_fr.inf alongside Dela_fr.bin
- Regenerate binary index if needed
- Use UNITEX tools to compress the dictionary

### Issue: Strange characters in concord.html
**Cause**: Encoding issues
**Solution**:
- Verify all input files are UTF-8
- Check Alphabet.txt includes all special characters
- Open HTML with UTF-8 supporting browser
